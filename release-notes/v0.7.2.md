# Release v0.7.2

Security patch release upgrading the Node.js runtime following the 21 October 2026 security advisory.

## Release highlights

- Upgrades development and production Docker images to Node.js 24.22.1, addressing the Brotli remote code execution vulnerability (CVE-2026-111497) and other Node.js security issues, including TLS certificate-validation bypasses.
- Requires Node.js 24.22.1 or later within the 24.x release line for local development and deployment.

## Details

- Pins all application Docker stages and the devcontainer Node.js feature to the patched runtime.
- Makes CI select the latest Node.js 24 release rather than relying on an older cached runtime.
- Includes the GitHub Actions updates already present on master and preserves the production prompt-template fixes from v0.7.1.
- Updates runtime prerequisites and documents container rebuilds and runtime-version verification.

## Upgrade notes

- Rebuild and redeploy the application image. Restarting an existing container or running `npm audit fix` does not update its Node.js runtime.
- Rebuild existing devcontainers and upgrade standalone Node.js installations to 24.22.1 or later within 24.x.
- The HTTP API, application dependencies and environment-variable contract are unchanged.
- See the [official Node.js security advisory](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases).
