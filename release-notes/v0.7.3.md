# Release v0.7.3

Security patch release upgrading dependencies to address published npm advisories without downgrading any package.

## Release highlights

- Resolves nine `npm audit` findings through upgrades only, including fixes for `body-parser`, `follow-redirects`, `multer`, `qs`, `zod`, `minimatch`, the ESLint toolchain and NestJS packages.
- Raises the `multer` override to 2.5.0 and pins `minimatch` to the patched 11.0.9 release. No package was downgraded.
- Reorders imports across the codebase to comply with the updated `eslint-plugin-import-x` import-order rule. No lint rule was weakened or disabled.

## Details

### Dependency upgrades

- `npm audit fix` applied 73 package upgrades within existing semver ranges, with zero downgrades verified against the previous lockfile.
- Overrides updated: `multer` 2.4.0 to 2.5.0, and `minimatch` 11.0.9 added to replace the vulnerable 10.2.6 resolution.
- Notable upgrades include `eslint` 10.12.0 to 10.15.0, `@typescript-eslint/*` 8.71.1 to 8.73.0, `@nestjs/platform-express` 12.1.2 to 12.5.1, `zod` 4.6.5 to 4.6.7 and `follow-redirects` 1.16.1 to 1.16.3.
- Includes the dependabot upgrades already present on master: `fast-uri`, `@google/genai`, `eslint-plugin-jsdoc`, `dotenv`, `@types/node` and `prettier`.

### Lint compliance

- `eslint-plugin-import-x` 4.18.1 orders parent imports before sibling imports. Import declarations were reordered to satisfy the existing `import-x/order` rule; the rule configuration is unchanged.

### Known upstream issue

- 21 high-severity findings remain, all caused by `picomatch` up to and including 4.0.7 (CVE-2026-112366), which has no patched release.
- npm's only remedies are major downgrades of `vitest`, `@vitest/coverage-v8`, `@stylistic/eslint-plugin`, `lint-staged`, `eslint-plugin-sonarjs`, `@nestjs/schematics` and `@nestjs/cli`. These were deliberately not applied.

## Verification

- ESLint, the British-English compliance check and the formatter pass.
- The production build passes.
- The unit suite passes with 752 tests across 57 test files.
- The mocked E2E suite passes with 64 tests and one existing todo.
- `npm audit` reports 21 high-severity findings, down from 30, with zero downgraded packages.

## Upgrade notes

- The HTTP API and environment-variable contract are unchanged.
- Rebuild and redeploy the application image to pick up the upgraded dependencies.
